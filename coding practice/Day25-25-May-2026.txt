====================================================
1. Ansible — Deploy App Using Git
====================================================

---
- name: Deploy app from Git for Pathnex
  hosts: all
  become: yes

  tasks:
    - name: Install git
      yum:
        name: git
        state: present

    - name: Clone repository
      git:
        repo: "https://github.com/pathnex/app.git"
        dest: "/opt/pathnex-app"

3. Kubernetes — Rolling Update Strategy
====================================================

apiVersion: apps/v1
kind: Deployment

metadata:
  name: pathnex-rollout

spec:
  replicas: 3

  strategy:
    type: RollingUpdate

    rollingUpdate:
      maxSurge: 2
      maxUnavailable: 1

  selector:
    matchLabels:
      app: rollout

  template:
    metadata:
      labels:
        app: rollout

    spec:
      containers:
        - name: app
          image: nginx

Commands Practiced:

mkdir k8s-day19
cd k8s-day19
vim rollout.yml
kubectl apply -f rollout.yml
kubectl get deployments
kubectl get pods
kubectl set image deployment/pathnex-rollout app=nginx:latest
kubectl rollout status deployment/pathnex-rollout

4. Shell Script — Check Internet Connectivity
====================================================

#!/bin/bash

ping -c 2 google.com &> /dev/null

if [ $? -eq 0 ]; then
  echo "Internet is available"
else
  echo "No internet connection"
fi

5. Jenkins Pipeline — Manual Approval
====================================================

pipeline {
    agent any

    environment {
        INSTITUTE_NAME = "Pathnex"
    }

    stages {
        stage('Deploy') {
            steps {
                input message: "Approve deployment for $INSTITUTE_NAME?"
                sh 'echo "Deployment approved and executed!"'
            }
        }
    }
}

Commands Practiced:

mkdir jenkins-day19
cd jenkins-day19
vim Jenkinsfile
cat Jenkinsfile

Concept:
Deploy → Approval Request → Proceed/Abort → Deployment

6. GitLab CI — Manual Approval Job
====================================================

stages:
  - deploy

variables:
  INSTITUTE_NAME: "Pathnex"

deploy:
  stage: deploy
  image: alpine:latest

  script:
    - echo "Ready to deploy $INSTITUTE_NAME"
