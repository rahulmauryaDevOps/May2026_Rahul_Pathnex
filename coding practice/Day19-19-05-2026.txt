Day 13 Practice

1. Ansible Debugging

Fixed YAML syntax errors:
- Missing colon (:)
- Incorrect indentation
- Missing state: present

Correct Code:

---
- name: Broken
  hosts: all

  tasks:
    - name: Install Nginx
      yum:
        name: nginx
        state: present


2. Terraform Debugging

Fixed:
- resource spelling
- Missing quotes
- Invalid tag syntax

Correct Code:

resource "aws_instance" "BadEC2" {
  ami           = "ami-123"
  instance_type = "c5.large"

  tags = {
    Name = "Broken"
  }
}


3. Kubernetes Debugging

Fixed:
- Missing colons
- Incorrect indentation
- Invalid label syntax

Correct Code:

apiVersion: apps/v1
kind: Deployment

metadata:
  name: broken

spec:
  replicas: 2

  selector:
    matchLabels:
      app: broken

  template:
    metadata:
      labels:
        app: broken

    spec:
      containers:
        - name: app
          image: nginx


4. Jenkins Matrix Build

pipeline {
    agent any

    matrix {
        axes {
            axis {
                name 'JAVA_VERSION'
                values '8', '11', '17'
            }
        }

        stages {
            stage('Build') {
                steps {
                    sh "echo Building with Java $JAVA_VERSION"
                }
            }
        }
    }
}

6. GitLab CI Matrix Jobs

stages:
  - build

build:
  stage: build
  image: maven:3.8.1-jdk-17

  parallel:
    matrix:
      - JAVA_VERSION: ['8', '11', '17']

  script:
